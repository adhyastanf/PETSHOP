# Oyen UI Documentation

Documentation for `PETSHOP-UI`.

Recommended reading order:
1. `FRONTEND_ARCHITECTURE.md` — structure, auth proxy, data layer, i18n, state
2. `DESIGN_SYSTEM.md` — tokens, components, dialogs, states
3. `UI_PATTERNS.md` — page composition patterns
4. `CODING_STANDARDS.md` — TypeScript, structure, i18n rules
5. `DEVELOPMENT_GUIDE.md` — step-by-step for a new frontend feature

Product and API documents are maintained in the API project (`PETSHOP-API/docs/`):
- `PROJECT_CONTEXT.md`, `FEATURE_KNOWLEDGE.md`, `data/BUSINESS_RULES.md`
- `API_CONTRACT.md`, `AUTHORIZATION_MATRIX.md`
- `implementation/USER_STORIES.md`, `implementation/ACCEPTANCE_CRITERIA.md`, `implementation/DEFINITION_OF_DONE.md`
